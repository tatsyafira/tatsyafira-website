STEP 01 · CONDITIONALS

What Are Conditional Sentences?

Ready

THE CORE IDEA

ConditionIf-clause — what must happen or be imagined.
→
ResultMain clause — what follows from the condition.

Conditional sentences adalah kalimat yang menghubungkan sebuah condition (kondisi) dengan sebuah result (hasil).

Conditional sentence umumnya terdiri dari dua bagian:

  • If-clause → menyatakan kondisi
  • Main clause → menyatakan hasil atau konsekuensi

Basic Structure

“

If + condition, result.

Example:

“

If it rains, we will stay at home.

If it rains adalah if-clause, sedangkan we will stay at home adalah main clause.

Urutan kedua bagian tersebut dapat dibalik tanpa mengubah makna:

“

If it rains, we will stay at home.

“

We will stay at home if it rains.

Jika if-clause berada di awal kalimat, biasanya digunakan koma. Jika main clause berada di awal, koma biasanya tidak digunakan.

“

If I study hard, I will pass the exam.

“

I will pass the exam if I study hard.

STEP 02 · CONDITIONALS

Open and Unreal Conditions

Ready

Conditional sentences dapat menunjukkan kondisi dengan tingkat kenyataan yang berbeda.

Oxford membedakan kondisi menjadi dua konsep utama:

Open condition

Kondisi yang masih terbuka terhadap kemungkinan. Kondisi tersebut mungkin benar, mungkin terjadi, atau mungkin menjadi benar.

“

If you join the library, you can borrow books.

Keanggotaan perpustakaan belum diketahui. Kondisinya masih terbuka.

“

If it rains tomorrow, we will stay at home.

Hujan mungkin terjadi, tetapi belum diketahui apakah akan terjadi.

Unreal condition

Kondisi yang tidak benar, bersifat imajinatif, atau dipandang sebagai situasi yang lebih jauh dari kenyataan.

“

If I had more money, I would travel around the world.

Kalimat tersebut membayangkan situasi memiliki lebih banyak uang, sementara kondisi tersebut tidak sesuai dengan keadaan yang sedang dibicarakan.

“

If you had arrived ten minutes later, we would have been closed.

Kalimat tersebut membicarakan alternatif terhadap suatu kejadian masa lalu yang sebenarnya tidak terjadi.

Important Concept

Dalam conditional sentences, past form tidak selalu menunjukkan past time.

Contoh:

“

If I had more money, I would travel more.

Had merupakan bentuk past, tetapi kondisi yang dibicarakan adalah keadaan sekarang.

Past form dalam pola unreal conditional dapat digunakan untuk menunjukkan distance from reality, bukan hanya waktu lampau. Oxford menggunakan konsep ini dalam penjelasan Type 2. oxford grammar

TypeStructureMain Meaning

STEP 04 · CONDITIONALS

ZERO CONDITIONAL

Ready

CONDITIONAL DISTANCE

ZEROgeneral / automaticPresent → Present

Form

“

If + Present Simple, Present Simple

Examples

“

If you heat ice, it melts.

“

If you don't water plants, they die.

“

If I drink coffee at night, I can't sleep.

Meaning and Use

Zero Conditional digunakan untuk menyatakan hubungan antara kondisi dan hasil yang bersifat:

  • general
  • repeated
  • automatic
  • regularly occurring

Contoh:

“

If you heat ice, it melts.

Hubungan antara kondisi dan hasil dianggap berlaku secara umum.

Contoh lain:

“

If I skip breakfast, I get hungry before lunch.

Kalimat tersebut menggambarkan hasil yang berulang, bukan satu kejadian tertentu.

Oxford menjelaskan Type 0 sebagai pola if + present + present yang dapat menunjukkan bahwa satu hal secara otomatis mengikuti hal lainnya. oxford grammar

If and When

Dalam kondisi yang bersifat umum atau berulang, when dapat digunakan sebagai alternatif dari if.

“

If I reverse the car, it makes a funny noise.

“

When I reverse the car, it makes a funny noise.

When menekankan bahwa hasil tersebut terjadi setiap kali kondisi terjadi.

Zero Conditional and Future Situations

Zero Conditional juga dapat digunakan untuk hasil otomatis dari sebuah kemungkinan future.

“

If the team win tomorrow, they get promotion to a higher league.

Dengan demikian, Zero Conditional tidak terbatas pada scientific facts.

In Case vs If

Ready

IF vs IN CASE

IF

Action happens if the condition occurs.

IN CASE

Action is taken now as a precaution.

In case dan if memiliki fungsi yang berbeda.

IF

“

I'll draw some money out of the bank if I need it.

Artinya uang akan diambil jika kebutuhan tersebut terjadi.

IN CASE

“

I'll draw some money out of the bank in case I need it.

Artinya uang diambil sebagai tindakan berjaga-jaga karena kebutuhan tersebut mungkin terjadi.

Comparison

“

if → condition

“

in case → precaution against a possible situation

Oxford memberikan perbedaan ini secara eksplisit. oxford grammar

STEP 35 · CONDITIONALS

Common Mistakes

Ready

01. If + Will

❌ If it will rain tomorrow, we will stay home.

✅ If it rains tomorrow, we will stay home.

02. If + Would

❌ If I would have more money, I would travel.

✅ If I had more money, I would travel.

03. If + Would Have

❌ If I would have known, I would have helped you.

✅ If I had known, I would have helped you.

04. Second Conditional = Impossible

❌ Second Conditional selalu berarti impossible.

✅ Second Conditional dapat menyatakan unreal, imaginary, atau theoretical situation.

05. Third Conditional = Regret

❌ Third Conditional hanya digunakan untuk regret.

✅ Third Conditional digunakan untuk unreal past condition dan imagined past result. Regret merupakan salah satu penggunaan yang umum.

06. IF = IN CASE

❌ If dan in case selalu memiliki makna yang sama.

✅ If menyatakan condition, sedangkan in case dapat menunjukkan tindakan precaution terhadap kemungkinan tertentu.
